# ⚡ CyberPulse Security Hub

A lightweight, modern Python web utility built with **Streamlit** that features a real-time password strength analyzer and a secure random password generator. Designed for quick deployment and clean UI aesthetics.

## 🚀 Features
- **Password Strength Checker:** Instantly evaluates password security based on length, uppercase/lowercase letters, digits, and special characters.
- **Secure Password Generator:** Generates highly secure, customizable passwords with a single click.
- **Responsive UI:** Clean and modern interface built entirely in Python.

## 🛠️ Tech Stack
- **Python** (Core Logic & Functions)
- **Streamlit** (Frontend Web Framework)
